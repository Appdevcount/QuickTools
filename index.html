The Logic Behind These Tools
Every visible problem is an effect. These tools exist to find the cause —
before it repeats. Not all tools, not always. Only the one that fits the question.

This is not a workflow to follow. It is an adaptive engineering system — four layers that together cover the full lifecycle from prevention to recovery. You reach for a tool only when the moment calls for it.

Layer Tools Purpose
Prevent ADR · API Contract · DoD · System Design Stop the cause before the effect forms
Monitor DORA · OKR · Work Distribution · 1-on-1 Catch drift before it becomes a crisis
Diagnose Risk Register · Sprint Retro · TDD Gap Find the cause after the effect surfaces
Recover Estimation · Capacity Planner · Project Tracker Rebuild with clarity, not guesswork

Why not call it a "Resilient System"? Resilience covers recovery well — but this toolkit also prevents failure before it forms, which is robustness. Adaptive Engineering System is the fuller name: design → observe → diagnose → recover → redesign.
