What is the Well-Architected Framework?

The Azure Well-Architected Framework (WAF) is a set of five pillars — Reliability, Security, Cost Optimization, Operational Excellence, and Performance Efficiency — that Microsoft recommends for evaluating cloud workload design. This tool lets you self-assess a workload against the framework's official design principles and checklist, score your current maturity, and produce a shareable report.

How to use this tool

1. Open each pillar tab and read its design principles before scoring.
2. For every checklist item, rate your current state: 0 = Not present, 1 = Partial, 2 = Implemented, 3 = Excellent.
3. Optionally set a priority weight per pillar if some matter more to this workload than others.
4. Visit the Dashboard tab to see your composite score, radar chart, and top improvement opportunities.
5. Save a milestone whenever you complete a review pass, so you can track progress over time.

Tips from Microsoft's assessment guidance

• Treat the assessment as a collaborative exercise — participants should feel safe discussing shortcomings openly.
• For brownfield (already-deployed) workloads, re-assess on a regular cadence, e.g. every 3-4 months.
• For greenfield workloads, use the assessment during initial design to establish a baseline.
• Consider scoring one pillar at a time rather than all 59 items in a single sitting.
• This is a local, offline tool — it does not connect to Azure Advisor or your subscription. For a live, Advisor-integrated review, use the official Azure Well-Architected Review.

Specialized reviews (external)

For deeper, technology-specific assessments beyond the core framework, Microsoft also publishes:

• AI workload review
• SaaS workload review
• Data Services review
• Azure Advisor — live, subscription-aware recommendations (not integrated into this offline tool)
